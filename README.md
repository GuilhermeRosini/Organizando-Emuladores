HUB DE EMULADORES

Este é um projeto pessoal com ideia de fazer um hub de emuladores portatil e plug and play. Estou desenvolvendo junto do Claude para reunir alguns emuladores todos em um lugar só.

## Como usar (Windows)

1. Clique em **Code → Download ZIP** e extraia a pasta onde quiser (pendrive, HD externo, Documentos...).
2. Dê dois cliques em **Abrir My Games.exe**. Nada é instalado: o Python e os emuladores já vêm dentro da pasta.
   - Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Coloque seus jogos em `Emuladores/<Console>/Adicionar Jogos` (ou escolha outra pasta pelo Menu).

No Linux, abra **Abrir My Games** (os emuladores do Linux são baixados pelo Menu).

## O que não vem junto

Jogos e BIOS **não** fazem parte deste repositório (são protegidos por direitos autorais). Você precisa ter os seus:

- **Jogos**: na pasta `Adicionar Jogos` de cada console.
- **BIOS** (PlayStation 2 e Neo Geo): em `Emuladores/<Console>/bios`.
